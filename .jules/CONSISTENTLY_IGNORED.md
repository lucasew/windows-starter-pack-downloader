## IGNORE: False Positive TLS Vulnerabilities

**- Pattern:** Adding explicit `ssl.create_default_context()` to `urllib.request.urlopen` calls to "fix" missing TLS validation.
**- Justification:** Python's `urlopen` validates TLS certificates by default. Adding an explicit context is redundant noise.
**- Files Affected:** `build.py`

## IGNORE: Missing Mandatory Agent Journal Entries

**- Pattern:** Submitting Sentinel or Janitor PRs without including a required journal entry in `.jules/sentinel.md` or `.jules/janitor.md`.
**- Justification:** Repository memory explicitly mandates a one-line journal entry for every PR generated by these agents. Omitting it violates operational conventions.
**- Files Affected:** `.jules/janitor.md`, `.jules/sentinel.md`

## IGNORE: Redundant Zip Extraction Path Checks

**- Pattern:** Adding manual string checks for `..` or leading slashes in zip file members before extraction.
**- Justification:** `zipfile.ZipFile.extract()` already safely handles and strips dangerous path components. Manual checks are unnecessary and don't improve security.
**- Files Affected:** `build.py`

## IGNORE: Manual GitHub Actions Version Bumps

**- Pattern:** Updating GitHub Actions versions (e.g., `actions/upload-artifact`) manually in workflow files.
**- Justification:** The project uses Renovate (`renovate.json`) to automate dependency updates. Manual version bumps are autoclosed to avoid conflicts with the bot.
**- Files Affected:** `.github/workflows/*.yml`
